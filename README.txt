# 오늘의 청춘 BGM - YouTube 바로 재생 버전

랜덤으로 노래를 뽑으면 사이트 안에 YouTube 플레이어가 나타나고,
해당 YouTube 영상을 페이지 안에서 재생합니다.

## 실행
1. 압축을 풉니다.
2. index.html을 브라우저에서 엽니다.
3. '오늘의 노래 뽑기'를 누릅니다.

## 노래 수정
script.js의 songs 배열을 수정하세요.

예:
{
  title: "노래 제목",
  artist: "가수 이름",
  message: "추천 문구",
  youtube: "https://www.youtube.com/watch?v=영상ID"
}

YouTube 영상 URL을 그대로 넣어도 됩니다.
